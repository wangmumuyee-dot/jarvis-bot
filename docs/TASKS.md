# 个人 Jarvis 机器人技术任务清单

## 1. 交付原则

本项目第一阶段目标是 7 天内完成可真实试用的 MVP。

优先级原则：

1. 飞书消息收发必须先跑通
2. SQLite 是唯一真实数据源
3. 提醒可靠性优先于功能数量
4. 安全过滤必须早于 LLM 调用
5. Obsidian 写入按 PARA 受控组织
6. 所有路径和密钥通过配置管理
7. 每天都要有可验证交付物

## 2. 里程碑总览

| 天数 | 主题 | 核心交付 |
| --- | --- | --- |
| Day 1 | 飞书收发消息 | 机器人私聊可收发 |
| Day 2 | SQLite + 记账 | 能记账到数据库 |
| Day 3 | 待办 + 提醒 | 能创建提醒并到点推送 |
| Day 4 | Obsidian | 能写入 PARA Markdown |
| Day 5 | LLM 意图识别 | 能识别真实自然语言 |
| Day 6 | 链接总结 + Excel | 链接入库和账本导出 |
| Day 7 | 验收 | 进入真实试用 |
